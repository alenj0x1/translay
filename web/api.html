API de Translay

Todo lo que hace la app (bibliotecas, importar, la cola, transcripciones, exportar) también se puede pedir por HTTP, y los webhooks avisan cuando algo pasa.

Autenticación

Crea una clave en Preferencias → Acceso y API → Claves de API: para todas las bibliotecas o una, de lectura o escritura. Mándala en cada pedido:

curl -H "Authorization: Bearer vt_…" http://localhost:8765/api/v1/libraries

Desde el mismo equipo donde corre la app, sin clave, la API responde como al dueño. Para entrar desde otros equipos, activa «Acceso desde otros equipos».

# importar un video y avisar a la cola que va primero
curl -X POST -H "Authorization: Bearer vt_…" -H "Content-Type: application/json" \
     -d '{"urls": ["https://www.youtube.com/watch?v=dQw4w9WgXcQ"], "priority": true}' \
     http://localhost:8765/api/v1/libraries/principal/import

Errores: 401 sin clave válida · 403 clave de solo lectura · 404 no existe o no se puede ver · 400 datos inválidos. El cuerpo trae {"error": "…"}.

Webhooks

En Preferencias → Acceso y API → Webhooks agrega una URL, elige los eventos y de qué bibliotecas. Cada aviso es un POST JSON:

POST https://tu-servidor/hook
X-VT-Event: video.procesado
X-VT-Delivery: 3f9a1c2b4d5e
X-VT-Signature: sha256=…

{"event": "video.procesado", "time": 1730000000.0, "vault": "ciencia",
 "data": {"video": "yt_…", "title": "…"}}

Si tu servidor no responde 2xx, se reintenta a los 10 s, 1 min y 5 min. cola.cambio y descarga.progreso llegan agrupados (el último cada 5 s).

Para comprobar que el aviso viene de tu app, calcula el HMAC-SHA256 del cuerpo con el secreto del webhook:

# Python
import hmac, hashlib
ok = hmac.compare_digest("sha256=" + hmac.new(SECRETO.encode(), cuerpo, hashlib.sha256).hexdigest(),
                         cabeceras["X-VT-Signature"])

// Node
const ok = crypto.timingSafeEqual(
  Buffer.from("sha256=" + crypto.createHmac("sha256", SECRETO).update(cuerpo).digest("hex")),
  Buffer.from(req.headers["x-vt-signature"]));

Eventos: video.agregado, video.descargado, video.procesado, video.error, video.movido, video.eliminado, coleccion.creada, coleccion.cambio, coleccion.eliminada, biblioteca.creada, biblioteca.cambio, biblioteca.eliminada, cola.cambio, cola.pausa, cola.terminada, descarga.progreso, exportacion.lista, exportacion.error, glosario.cambio, comentario.cambio, youtube.bloqueo.
