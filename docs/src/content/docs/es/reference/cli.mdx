`python run.py --version` muestra la versión instalada (<code>Translay {version.version}</code>).

## Variables de entorno

| Variable | Para qué |
|---|---|
| `TRANSLAY_OWNER_PASSWORD` | Contraseña del dueño al arrancar; equivale a `--owner-password`. Ver [Acceso](../../integrations/access/). |
| `TRANSLAY_ORIGINS` | Otros orígenes permitidos, separados por comas; equivale a `--allow-origin`. Ver [Otros sitios web](../../integrations/access/#otros-sitios-web). |
| `HF_HOME` | Dónde se guardan los modelos descargados de Hugging Face (en Docker, `/models`). |
| `CT2_CUDA_CACHING_ALLOCATOR_CONFIG` | Caché de memoria de CTranslate2; `vt/gpu.py` lo limita a 400 MB si no está definido. |

## Ejemplos

```sh
# sin GPU (lento, útil para probar la interfaz)
python run.py --device cpu --compute-type int8 --voice none

# otro traductor y otro puerto
python run.py --translator nllb-1.3b --port 9000

# escuchar en toda la red (además de «Acceso desde otros equipos» en Preferencias)
python run.py --host 0.0.0.0
```
