## Inicio de sesión de la vista

| Método | Ruta | Cuerpo |
|---|---|---|
| `POST` | `/api/auth/login` | `{"password": "…", "vault": "<id>"}` (sin `vault`: contraseña del dueño) |
| `POST` | `/api/auth/logout` | — |
| `GET` | `/api/auth/me` | — devuelve `{owner, perms, local}` |

La tabla de rutas sale del docstring de `vt/api.py`: al agregar una ruta, documéntala ahí.
