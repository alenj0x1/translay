The desktop app is the same Translay interface inside its own window: everything in this guide works the same. Under the hood, the app starts the Translay server without a window and shuts it down when you quit (see [Architecture](../../how-it-works/architecture/#desktop-app)).

## The window

- The Translay header is the title bar: drag it to move the window and double-click to maximize or restore it. It follows the light or dark theme, like the window border.
- On the right, **Ajustes** (Settings) and the light/dark switch appear as icons, next to minimize, maximize and close. When the window is narrow, the buttons switch to icons and the search box shrinks, so the window buttons are always visible.
- On Windows 11, resting the mouse on maximize or holding it down opens the snap layouts, to choose where the window goes, as in any window (Windows 10 doesn't have them).
- When a new version is available, an extra icon appears there; it opens the updates section.
- The subtitles icon opens or closes the [live subtitles over any window](#live-subtitles-over-any-window); while they are shown, the icon stays marked.
- Translay opens only once: if you open it again from the Start menu, the window that was already open comes back.
- On launch, the startup screen shows your background scene (the one chosen in Settings › Apariencia; the «Translay» scene the first time) and, below it, the logo, what is loading in words (checking the computer, downloading a model with its percentage, loading speech recognition, loading the translator) and a rotating tip about the app. It opens with the theme, accent color and language you used last time; the setup screens of the first launch look the same.
- The window, the taskbar, the Start menu and the installer use the Translay icon: the voice wave in violet on a dark square.

## First launch: the wizard

On the first launch, after you choose the profile, a wizard sets up Translay while the voice engine and the models download (the steps are in [Installation](../../getting-started/install/#steps)): language, how you'll use it, your library, appearance, the agent, YouTube, access from your phone and a few demos of what Translay does. Its bottom strip keeps showing the download.

- Each choice is saved as you make it, in the app's own settings (`desktop.json`), so closing the window halfway loses nothing.
- When the wizard ends, the window waits until the server is ready (or shows the startup strip with tips meanwhile) and opens Translay. On that first load, Translay applies what you chose with its own preferences, renames and recolors the Main library, opens the YouTube sign-in if you asked for it and turns on access from other devices if you allowed it. Then it forgets those choices: they are applied only once.
- The welcome dialog that Translay shows in the browser (with `run.py` or Docker) never appears in the app: the wizard already asked all of it.
- **Ver la bienvenida** (Settings › App de escritorio) opens the wizard again over what is installed, without downloading anything; when it ends, Translay comes back with only what you changed there applied.

## Settings › App de escritorio

This page only appears in the app.

| Option | What it does |
|---|---|
| **Subtítulos en vivo** (Live subtitles) | **Visibles** (Shown) opens the live subtitles strip over every window; **Ocultos** (Hidden) closes it. The same as the title bar button (see [Live subtitles over any window](#live-subtitles-over-any-window)). |
| **Al cerrar la ventana** (When closing the window) | **Salir** (Quit) closes Translay completely. **Minimizar a la bandeja** (Minimize to tray) hides the window and leaves Translay in the system tray while the queue has work: it keeps downloading, translating and exporting; when it finishes, Translay quits by itself and frees everything. If the queue is stopped or nothing is being processed, it quits anyway (the setting says so). From the tray icon, **Abrir Translay** (Open Translay) or **Salir**. |
| **Biblioteca Principal** (Main library) | The folder where the Main library is stored. **Abrir carpeta** (Open folder) opens it in Explorer; **Cambiar…** (Change…) picks another and Translay restarts with it. Other libraries can be in any folder (see [Libraries](../libraries/)). |
| **Registros** (Logs) | Opens the folder with `setup.log` (the installation) and `server.log` (what the server writes). Useful for reporting a problem. |

## Live subtitles over any window

The subtitles button in the title bar (or **Subtítulos en vivo** in Settings › App de escritorio) opens a strip at the bottom of the screen with the live translation of whatever the computer is playing: a video call, a game, a stream, a video in another app. It shows one or two lines on a dark rounded box: the sentence being said and, fainter above it, the previous one. It translates into the language of **Traducir a** (Translate to, Settings › Uso); what is spoken in your own language is only transcribed.

- **It doesn't get in the way.** The strip stays above every window, never takes the keyboard and lets clicks through to the window behind it.
- **Moving it.** Hover over the strip and a handle appears at its left edge: drag the handle to put the strip anywhere, on any screen. Translay remembers where you left it. Only the handle takes the mouse; the rest of the strip keeps letting clicks through.
- **Nothing is saved.** What the strip recognizes and translates never goes to a library, the transcripts or the history: the server keeps only the last sentences in memory while it is open.
- **What it hears.** The sound of the default output device (speakers or headphones), as Windows mixes it, including Translay's own sound. If you change the output device, the strip follows it. When nothing has been said for a few seconds, the strip fades out until there is speech again.
- It closes with Translay, with the button again or when the server stops. While it is open, Translay doesn't quit by itself from the tray.

<Aside>
The live subtitles use the same recognition and translation as a recording in progress, on the GPU. They are available only in the desktop app, to the owner on this computer (see [Access](../../integrations/access/)).
</Aside>

## Updates

Translay looks for new versions on [GitHub Releases](https://github.com/alenj0x1/translay/releases) and tells you when there is one.

- **Buscar actualizaciones** (Check for updates): **Automáticamente** (Automatically; when Translay opens and every 6 hours) or **Manualmente** (Manually). With a new version you get a notice and an icon in the title bar.
- The **Buscar actualizaciones** button checks right away. If there is a new version, it shows its notes and **Descargar …** (Download …, with the version), which opens the installer in your browser. Run it as usual: it installs over the current version and your libraries, preferences and installed runtime stay as they were; if the new version needs other packages, they are installed on the next launch.
- The app never downloads or runs an installer by itself; it only opens Translay's releases on GitHub.

## If the server stops

The window shows **Translay se detuvo** (Translay stopped) with the server's last lines, **Reintentar** (Retry; starts it again) and **Abrir registros** (Open logs). Closing the app also closes the server and everything it launched (models, voice, downloads, ffmpeg), even if the app is killed abruptly: nothing is left using the GPU or RAM.

## Same machine, another browser

The app's server listens on `127.0.0.1` (port 8765 or the next free one). The window only opens that address: the one the app chose when starting the server, announced by the server on its own output. To connect from your phone or another device on the network, turn on access in **Ajustes › Acceso y API** (Settings › Access and API) (see [Access](../../integrations/access/)).
