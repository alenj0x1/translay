The desktop app is the same Translay interface inside its own window: everything in this guide works the same. Under the hood, the app starts the Translay server without a window and shuts it down when you quit (see [Architecture](../../how-it-works/architecture/#desktop-app)).

## The window

- The Translay header is the title bar: drag it to move the window and double-click to maximize or restore it. It follows the light or dark theme, like the window border.
- On the right, **Ajustes** (Settings) and the light/dark switch appear as icons, next to minimize, maximize and close. When the window is narrow, the buttons switch to icons and the search box shrinks, so the window buttons are always visible.
- On Windows 11, resting the mouse on maximize or holding it down opens the snap layouts, to choose where the window goes, as in any window (Windows 10 doesn't have them).
- When a new version is available, an extra icon appears there; it opens the updates section.
- Translay opens only once: if you open it again from the Start menu, the window that was already open comes back.
- On launch you see **Abriendo Translay** (Opening Translay) while the models load, with the theme you used last time.

## Settings › App de escritorio

This page only appears in the app.

| Option | What it does |
|---|---|
| **Al cerrar la ventana** (When closing the window) | **Salir** (Quit) closes Translay completely. **Seguir en la bandeja** (Keep running in the tray) hides the window and leaves Translay in the system tray while the queue has work: it keeps downloading, translating and exporting; when it finishes, Translay quits by itself and frees everything. If the queue is stopped or nothing is being processed, it quits anyway (the setting says so). From the tray icon, **Abrir Translay** (Open Translay) or **Salir**. |
| **Biblioteca Principal** (Main library) | The folder where the Main library is stored. **Abrir carpeta** (Open folder) opens it in Explorer; **Cambiar…** (Change…) picks another and Translay restarts with it. Other libraries can be in any folder (see [Libraries](../libraries/)). |
| **Registros** (Logs) | Opens the folder with `setup.log` (the installation) and `server.log` (what the server writes). Useful for reporting a problem. |

## Updates

Translay looks for new versions on [GitHub Releases](https://github.com/alenj0x1/translay/releases) and tells you when there is one.

- **Buscar actualizaciones** (Check for updates): **Automáticamente** (Automatically; when Translay opens and every 6 hours) or **Solo a mano** (Only manually). With a new version you get a notice and an icon in the title bar.
- The **Buscar actualizaciones** button checks right away. If there is a new version, it shows its notes and **Descargar …** (Download …, with the version), which opens the installer in your browser. Run it as usual: it installs over the current version and your libraries, preferences and installed runtime stay as they were; if the new version needs other packages, they are installed on the next launch.
- The app never downloads or runs an installer by itself; it only opens Translay's releases on GitHub.

## If the server stops

The window shows **Translay se detuvo** (Translay stopped) with the server's last lines, **Reintentar** (Retry; starts it again) and **Abrir registros** (Open logs). Closing the app also closes the server and everything it launched (models, voice, downloads, ffmpeg), even if the app is killed abruptly: nothing is left using the GPU or RAM.

## Same machine, another browser

The app's server listens on `127.0.0.1` (port 8765 or the next free one). To connect from your phone or another device on the network, turn on access in **Ajustes › Acceso y API** (Settings › Access and API) (see [Access](../../integrations/access/)).
