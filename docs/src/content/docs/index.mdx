  <Card title="Dubbing in their own voice" icon="seti:audio">
    Whisper transcribes, Opus-MT translates and OmniVoice clones the voice of each person in the video. The voice stays in sync with the picture.
  </Card>
  <Card title="YouTube and files" icon="seti:video">
    Paste a link, a playlist or a CSV with thousands of links; they are downloaded and processed automatically in a queue.
  </Card>
  <Card title="Libraries" icon="open-book">
    Collections, channels, categories and search across all transcripts. Each library in its own folder.
  </Card>
  <Card title="Desktop app" icon="laptop">
    A Windows installer: the app sets up Python, the server and the voice engine by itself, and opens Translay in its own window.
  </Card>
  <Card title="API and webhooks" icon="puzzle">
    Everything the app does is also available over HTTP, with per-library keys and signed notifications.
  </Card>
