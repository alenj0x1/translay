## Requisitos

| | |
|---|---|
| GPU | NVIDIA con 8 GB o más (probado en una RTX 4060 de 8 GB). Sin GPU funciona con `--device cpu`, muy lento y sin voz práctica. |
| Python | 3.11 o más nuevo para el servidor; el motor de voz usa su propio entorno con Python 3.11. |
| [uv](https://docs.astral.sh/uv/) | Para crear el entorno del motor de voz. |
| ffmpeg | En el `PATH`: descargas, miniaturas y exportar. |
| Node.js 20+ | En el `PATH`: yt-dlp lo usa para el desafío de JavaScript de YouTube. |
| Disco | ~15 GB para modelos y entornos, más lo que ocupen tus videos. |

<Aside>¿Prefieres no instalar nada de esto? Usa [Docker](../docker/).</Aside>

## Pasos

Cada versión publicada está en [Releases](https://github.com/alenj0x1/translay/releases), con sus notas; el código siempre está en [GitHub](https://github.com/alenj0x1/translay).

<Steps>

1. Clona el repositorio e instala lo del servidor:

   ```sh
   git clone https://github.com/alenj0x1/translay.git
   cd translay
   pip install -r requirements.txt
   ```

   En Linux, si tu sistema ya tiene CUDA 12 y cuDNN 9, puedes quitar las líneas `nvidia-*` de `requirements.txt`.

2. Crea el entorno del motor de voz (OmniVoice con torch para CUDA 12.8):

   <Tabs syncKey="os">
   <TabItem label="Windows">
   ```powershell
   uv venv -p 3.11 .venvs/omnivoice
   uv pip install -p .venvs/omnivoice/Scripts/python.exe --torch-backend=cu128 omnivoice deepfilternet soundfile
   ```
   </TabItem>
   <TabItem label="Linux">
   ```sh
   uv venv -p 3.11 .venvs/omnivoice
   uv pip install -p .venvs/omnivoice/bin/python --torch-backend=cu128 omnivoice deepfilternet soundfile
   ```
   </TabItem>
   </Tabs>

3. Arranca:

   ```sh
   python run.py
   ```

   En Windows también sirve `iniciar.bat`. Se abre `http://127.0.0.1:8765`.

</Steps>

La primera vez se descargan los modelos de Hugging Face (Whisper large-v3-turbo, Opus-MT, OmniVoice y WeSpeaker, unos 6 GB) a la caché del usuario. Luego arranca en segundos y queda en [modo reposo](../../funcionamiento/gpu-y-reposo/) hasta que hay algo que procesar.

Todas las opciones de arranque: [Línea de comandos](../../referencia/linea-de-comandos/).

## Lo que se guarda

Todo lo tuyo (biblioteca, transcripciones, voces, preferencias, contraseñas con hash) queda en `data/`, que no entra en git. Detalle en [Datos en disco](../../funcionamiento/datos/).
