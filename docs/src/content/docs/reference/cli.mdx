`python run.py --version` prints the installed version (<code>Translay {version.version}</code>).

## Environment variables

| Variable | Purpose |
|---|---|
| `TRANSLAY_OWNER_PASSWORD` | Owner password at startup; same as `--owner-password`. See [Access](../../integrations/access/). |
| `TRANSLAY_ORIGINS` | Other allowed origins, comma-separated; same as `--allow-origin`. See [Other websites](../../integrations/access/#other-websites). |
| `HF_HOME` | Where downloaded Hugging Face models are stored (in Docker, `/models`). |
| `CT2_CUDA_CACHING_ALLOCATOR_CONFIG` | CTranslate2 memory cache; `vt/gpu.py` caps it at 400 MB if it is not set. |

## Examples

```sh
# no GPU (slow, useful for trying the interface)
python run.py --device cpu --compute-type int8 --voice none

# another translator and another port
python run.py --translator nllb-1.3b --port 9000

# listen on the whole network (in addition to "Acceso desde otros equipos" in Preferences)
python run.py --host 0.0.0.0
```
