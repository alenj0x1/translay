## UI sign-in

| Method | Route | Body |
|---|---|---|
| `POST` | `/api/auth/login` | `{"password": "…", "vault": "<id>"}` (without `vault`: the owner password) |
| `POST` | `/api/auth/logout` | — |
| `GET` | `/api/auth/me` | — returns `{owner, perms, local}` |

The route table comes from the docstring of `vt/api.py`: when you add a route, document it there.
