## Add a preference

1. Add an entry to `SCHEMA` in `vt/prefs.py` (with its `section`) and its group and description in `DETAILS`.
2. Read it in the UI (`prefs.<key>` in `web/js/`). The Settings screen builds itself.
3. If it should be per library, add it to `VAULT_PREFS` in `vt/vaults.py`.

This page regenerates itself when the documentation is built.
